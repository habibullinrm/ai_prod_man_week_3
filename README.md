# Прогноз ухода учеников: прототип (Gate 3)

Учебный прототип по курсу «Управление ML-продуктами» (ЦУ). Кейс B «отток → удержание» для Nastavnik,
сервиса подготовки к ЕГЭ.

**Задача.** В день продления модель ранжирует учеников по ожидаемой потере: вероятность уйти в ближайшие
30 дней × оставшиеся платежи. Куратор получает верх этого списка — кому звонить сегодня. Своих логов у
Nastavnik пока нет, поэтому прототип проверяется на открытом датасете OULAD (Open University, 2013–2014).

**Демо:** [`landing/index.html`](landing/index.html) — страница с интерактивным списком куратора,
четырьмя разобранными случаями (включая ошибку модели) и сравнением с таргетами Gate 2.

## Как устроено

- Снимки на дни курса 30, 60 … 210. Признаки берутся только из дней до снимка, метка — отчисление
  в следующие 30 дней.
- Обучение на потоках 2013 года, проверка на потоках 2014 года.
- Уходы до старта курса исключены (около 30% всех уходов): активности по ним нет.
- Сравниваются четыре подхода:
  - правило «7 дней без активности» (бейзлайн);
  - LightGBM на признаках активности;
  - LightGBM на активности и оценках;
  - логистическая регрессия на сплайнах с теми же признаками — продуктовая модель.

## Главные результаты (тест 2014: 15 608 учеников, 2 984 ухода)

| Модель | Доля пойманной потери в топ-20% | Прирост к правилу, 95% ДИ |
|---|---|---|
| Правило «7 дней» | 36,2% | — |
| LightGBM: активность | 36,3% | +0% (−5…+6%) |
| LightGBM: активность + оценки | 50,8% | +40% (+33…+48%) |
| LogReg (сплайны): активность + оценки | 50,9% | +40% (+33…+49%) |

- **Одни клики** не дают ничего сверх правила. Весь прирост приносят данные об учёбе: пропущенные задания и баллы.
- **Простая модель на тех же признаках** не хуже бустинга: разница от −3% до +3%. Зато вклады её признаков
  точно складываются в прогноз, и причины для куратора получаются честными.

## Данные

Датасет в репозиторий не входит: `studentVle.csv` весит 454 МБ, это больше лимита GitHub.
Скачайте OULAD со страницы <https://analyse.kmi.open.ac.uk/open_dataset> и распакуйте CSV в `data/oulad/`.
Другой путь можно задать переменной `OULAD_DIR`.

Kuzilek J., Hlosta M., Zdrahal Z. Open University Learning Analytics dataset. Scientific Data 4, 170171 (2017).
Лицензия CC BY 4.0.

## Запуск

```bash
uv sync
uv run python prototype/run_all.py --rebuild   # снимки → модели → бутстрап → графики → landing/data.json
uv run python landing/build_page.py            # data.json → landing/index.html
uv run python landing/check_page.py            # проверки страницы (нужен: uv run playwright install chromium)
```
